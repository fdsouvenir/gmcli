# gmcli v1.1.0 — sign in without cookie files

## Highlights

Run `gmcli auth`, sign in in the browser window, and tap the matching emoji
on your phone. You no longer need to create a file, export cookies, or open
browser developer tools for the default pairing flow.

- Automatically detect Chrome, Chromium, or Edge, with `--browser` for an
  explicit executable and `--browser-timeout` for more sign-in time.
- Use a private temporary browser profile, capture only the Google Messages
  credentials after sign-in, then close the browser and remove the profile.
  Existing browser profiles are never read. DBSC is disabled only for the
  temporary process so the session can be used by gmcli.
- Preserve `--cookies-file FILE` and `--cookies-file -` for existing scripts
  and servers without a desktop. Missing-file errors point to browser sign-in.
- Keep existing same-account refresh, phone emoji confirmation, and atomic
  private session writes. Failed or cancelled attempts preserve saved pairing.
- Update ClawHub guidance and its installer to gmcli v1.1.0. The skill still
  requires OpenClaw 2026.8.1 or newer and keeps archive queries read-only.

## Upgrade

Requires Go 1.25 or newer:

```sh
GOBIN="$HOME/.local/bin" go install github.com/fdsouvenir/gmcli@v1.1.0
gmcli auth
```

Browser sign-in requires a desktop display and an installed Chrome, Chromium,
or Edge browser on the machine running gmcli. Firefox remains available for
manual cookie input. See the [pairing instructions](https://github.com/fdsouvenir/gmcli#pair-with-a-google-account)
for remote-server setup and troubleshooting. No database migration is added.

Once available on ClawHub:

```sh
clawhub update google-messages-local-archive --version 1.1.0
```

## Validation

- Full Go tests and `go vet ./...`.
- Full race suite with `GMCLI_BROWSER_TEST=1`.
- A real Chrome process with intercepted test pages and synthetic cookies:
  capture, exact cookie-domain filtering, private profile permissions, and
  cleanup. The fixture is now included in CI.
- Default CLI flow, option validation, browser startup failure, cancellation,
  timeout, and preservation of the saved session.
- Versioned build, isolated-store CLI smoke checks, skill runtime preflight,
  and the official OpenClaw 2026.8.1 skill validator.

The browser fixture does not sign into a real Google account. Live Google
sign-in, phone pairing, and reauthentication have not been exercised during
this release. Google may impose account verification or browser restrictions;
the manual input flow remains available. No messages or reactions were sent.
