# gmcli v0.3.3 — archive skill health guidance

## Changes

- Update the Google Messages Local Archive skill to interpret `health_status`
  and the evidence-based doctor report shipped in v0.3.2.
- Remove the legacy sync-timestamp heuristic that could describe an unverified
  archive as a healthy quiet inbox.
- Explain nonzero JSON doctor exits, bounded recent evidence, quiet-phone
  uncertainty, snapshot discrepancies, and cached send-settings limits.
- Document Go 1.25, private backups, additive database migration, and restarting
  an existing sync process after installing an updated binary.
- Publish matching ClawHub installer metadata pinned to gmcli v0.3.3.

This is a documentation and skill patch on v0.3.2. The application's runtime
behavior and dependencies are unchanged. Google Account pairing remains in
[PR #4](https://github.com/fdsouvenir/gmcli/pull/4), pending its real-device checks.

## Install and upgrade

Requires Go 1.25 or newer:

```sh
GOBIN="$HOME/.local/bin" go install github.com/fdsouvenir/gmcli@v0.3.3
clawhub update google-messages-local-archive --version 0.3.3
```

Back up your database and session privately before upgrading. When upgrading
from versions before v0.3.2, store-opening commands apply the additive schema-4
migration, preserving archive rows. JSON doctor prints its report and exits
nonzero when it reports issues. Read-only protects against phone mutations;
it does not prevent local schema migration. Installing a binary does not
restart an existing sync process; arrange its restart separately.

## Verification and limits

Release validation includes `go test ./...`, `go vet ./...`, a versioned binary
build, and offline CLI smoke checks using an isolated temporary store. The
published ClawHub bundle is checked against the repository and installed in a
temporary workspace.

No phone pairing, messages, reactions, or live reconnection are performed by
this release. `recently_verified` remains bounded offline evidence, not proof
of present connectivity or complete historical recovery.
